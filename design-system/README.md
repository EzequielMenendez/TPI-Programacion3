## Rationale

The Global Evaluation specification ("Global de Programación III — Librería web integrada y desplegada en Easypanel") explicitly states that the frontend reuses the screens, HTML structure, and CSS stylesheet (`frontend/index.html`, `frontend/css/styles.css`) from the first midterm exam and connects them to the FastAPI backend via native JavaScript `fetch`. Neither a parallel design system nor per-change HTML mockups are required.
